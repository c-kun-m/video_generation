# G07｜配音、字幕与时间线

> 状态：DRAFT_FOR_REVIEW。交付阶段：B2。前置：G02–G06、G09 预算准入。下游：G08、G11–G14。

## 1. 目标与边界

在生成昂贵视频前，用实际语音和可视分镜验证节奏。字幕、镜头与声音共享明确的时间基准，避免逐段浮点四舍五入造成累计偏移。首版支持中文解说、直切和简单淡入淡出；多轨复杂剪辑、口型同步和音乐自动作曲不计入首版。

## 3. 时间数据合同

```json
{
  "schema_version": "timeline/v1",
  "timeline_id": "timeline_01",
  "revision": 2,
  "fps": {"num": 24, "den": 1},
  "total_frames": 720,
  "clips": [
    {"slot_id": "slot_01", "shot_ref": {"shot_id": "shot_01", "revision": 1}, "start_frame": 0, "duration_frames": 120, "transition_out_frames": 0}
  ],
  "narration": {"asset_ref": {"asset_id": "voice_01", "revision": 1}, "sample_rate": 48000, "start_sample": 0},
  "alignment_ref": "alignment_02"
}
```

实际快照应包含完整 clips；示例只显示一个片段。首版固定输出 fps=24/1，数据合同保留有理数表达以便后续支持 30000/1001。帧时间计算为 `frame × fps_den / fps_num`，音频时间为 `sample / sample_rate`。

转场有重叠时总时长为片段时长之和减去重叠，不能简单求和。空隙必须显式指定纯色/静帧片段，不允许通过“缺一个片段”隐含黑场。字幕转 SRT 时从绝对时间统一换算毫秒，不能累加各段取整误差。

## 4. 实现流程与交互

G05 剧本明确区分 narration_text、on_screen_text、visual_description。用户确认 narration_text 后生成试配音，G06 登记音频并用 ffprobe/解码探测取得实际长度。G07 保存声线、速度、采样率、停顿和生成来源。

优先使用供应商提供的分段时间戳；缺少时进行文本与音频强制对齐。强制对齐是把已知文字匹配到对应声音时间，不等于改写原文。对齐置信不足的段落显示待校正，不能凭平均字数把所有字幕当成准确结果。

根据实际语音长度和停顿安排镜头槽，G05 可提出分镜建议；时间线校验器检查不重叠/允许转场、总长度、音频覆盖和模型最大镜头时长。用户确认后 G03 保存时间线审批，G08 据此编译原生生成计划。

分镜预览使用静态图、文字卡、真实或临时旁白表现剪辑节奏，明确标为“分镜预览”；它不证明视频模型能实现动作。编排依赖是 G07 调用媒体端口，G13 提供该端口的统一实现；B2 可先完成此子集，B3 再完成成片导出能力。

## 5. 音频、字幕与变更规则

试配音经用户选定后可直接成为最终旁白，避免最终阶段重录导致时长漂移。用户更换声线、速度或文本时创建新 VoiceAsset，重新对齐和检查时间线；新语音时长相同也要重新验证字幕对齐。

仅修改字幕错别字或标点、且不修改朗读内容时，更新 SubtitleRevision 和合成依赖，不重新生成音频/镜头。若该字同时属于画面内生成文字或用户要求同步改旁白，G12 根据实际依赖增加失效范围，不能一概视为字幕独立修改。

首版默认每行不超过 18 个中文字符、最多 2 行；数字/英文按显示宽度计算，并提供人工调整。字幕至少展示 12 帧，不能超出有效时间线。样式、字体、位置与安全边距进入 SubtitleStyleProfile；最终以 G13 实际字体渲染检查为准。

音乐作为独立输入素材，记录开始位置、裁切长度、音量及淡入淡出。默认将音乐调整为低于人声的辅助音轨，但具体电平在输出 profile 中显式配置，不让模型生成任意滤镜命令。

## 6. 失败与实现任务

音频超过目标长度时提供缩短文稿、调整停顿/语速、延长目标三种可审查建议；在用户确认前停止冻结。不会通过截掉结尾或静默倍速解决冲突。

TTS 调用结果不确定按 G05/G04 处理；已上传旁白可以跳过供应商调用。对齐服务失败时允许人工标段。音频解码失败、采样率不支持、字幕超界或转场重叠超出片段长度均返回字段级错误。

实现任务：音频导入/探测 → TTS 适配 → 对齐数据与编辑 → 时间线 Schema/校验器 → 字幕文件与样式 → 静态分镜预览 → 修改影响事件接入。

## 7. 验收条件

- G07-A1：30 秒/720 帧示例的旁白、镜头、字幕绝对时间一致，输出总长度误差不超过一帧。
- G07-A2：加入转场后总长度按重叠计算正确；非法重叠与空洞被拒绝或显式补片段。
- G07-A3：长旁白触发冲突提示，系统没有静默截断、变速或改变批准内容。
- G07-A4：只改字幕显示文字不触发 TTS/镜头生成；更换声线必定检查时长与对齐。
- G07-A5：缺少时间戳的音频能人工校正；低置信段落不会被标成已精确对齐。
- G07-A6：分镜预览和真实候选在 UI 明确区分；选定旁白在最终合成中复用同一摘要。

## 8. 供审核的取舍

首版把配音安排在视频生成前，并使用经过确认的音频建立节奏。默认字幕排版和输出规格可以审核调整；禁止静默改变已批准内容和用估算时长冒充实测结果属于固定约束。
