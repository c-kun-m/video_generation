# B1 第一部分实施进度

目标：手动编辑需求、剧本和分镜，审批精确版本，冻结输入后通过真实 Temporal 运行模拟制作，验证暂停、取消、断线与进程重启恢复。

本轮不包含真实 Agent、ComfyUI、素材上传、配音、GPU 调度、预算和合成；不能据此宣称完整 B1 或生产环境验收完成。

## 分步目标

- [x] 1. 后端分层、共享命令处理、类型化内容和不可变版本。
- [x] 2. 版本审批、输入冻结、模拟制作批次与一致性查询。
- [x] 3. PostgreSQL Outbox/Inbox、Temporal 服务和 Worker、控制与恢复。
- [x] 4. React 编辑器、版本审批、演练状态、加密本地草稿与命令恢复。
- [x] 5. 增量迁移、合同同步、故障注入与端到端验收、运行文档。

## 验收要求

- 同命令 20 次并发只产生一份业务结果；不同请求复用 ID 拒绝。
- 新版本不继承审批；审批旧头拒绝；已启动批次使用冻结输入。
- 乐观并发冲突保留草稿；租户与角色边界有效。
- DB 提交后响应丢失可查原结果；Outbox 发送后崩溃不重复启动。
- Worker 重启、Activity 回报丢失不重复保存步骤结果。
- 暂停不派发下一步；恢复复用结果；取消与完成按持久化顺序裁决。
- 桌面、API、Worker、Temporal 重启后可恢复，游标缺口用快照恢复。
- 既有测试、合同和桌面构建通过。
